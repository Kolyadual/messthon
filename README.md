## 🌟 Почему Messthon?

В мире, где каждый мессенджер хочет знать о вас всё, **Messthon** предлагает радикально иной подход:

✅ **Никаких паролей** — только уникальные коды доступа  
✅ **End-to-end шифрование** — только вы видите свои сообщения  
✅ **Никакой телеметрии** — мы не следим за вами  
✅ **Локальное хранение** — все данные только на вашем устройстве  
✅ **Красивый интерфейс** — современный дизайн на Qt6  
✅ **Open Source** — код прозрачен и доступен каждому

## 🎯 Ключевые возможности

| | |
|---|---|
| 🔐 **Шифрование данных** | Все сообщения и история хранятся в зашифрованном виде на вашем ПК |
| 👥 **P2P архитектура** | Сервер только координирует, сообщения идут напрямую |
| 🎨 **Qt6 интерфейс** | Современный, отзывчивый, красивый дизайн |
| 🌍 **Работает везде** | Из любой точки мира с доступом в интернет |
| 💾 **История сообщений** | Сохраняется локально в зашифрованном виде |
| 🔑 **Коды доступа** | Никаких паролей — только уникальные коды |

## 🚀 Быстрый старт

### Clone
```bash
git clone https://github.com/Kolyadual/messthon.git
cd messthon
```

### Run

    bash systemr.sh

    ./run.sh server # It starts server

    ./run.sh client # It starts main messenger
